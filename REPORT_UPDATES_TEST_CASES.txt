WHAT CHANGED (read first)
--------------------------------------------------------------------------------
1. Admin -> Sales History no longer crashes when a unit carries an operational
   flag that has no display config (e.g. a repaired unit gets a 'repaired_unit'
   flag). Unknown flags are now skipped instead of throwing.

2. Processing a return now flags the linked sale by IMEI as well as unitId.
   Imported sales (from the SALES_REPORT workbook) have an IMEI but no unitId,
   so previously they were never marked as returned. They now are.

3. The in-app Reporting -> Sales tab ("Full Sales Log") is now return-aware:
   returned rows are tinted red with a "Returned" badge (hover shows the
   reason), and the CSV export has new "Returned" / "Return Reason" columns.
